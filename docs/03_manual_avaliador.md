# 3. Manual do avaliador

## Acesso

O avaliador deve utilizar a conta fornecida pela coordenação ou o mecanismo de autenticação definido pela instituição.

## Procedimento

1. Entrar na plataforma;
2. acessar a área de trabalhos atribuídos;
3. abrir o PDF, quando disponível;
4. analisar o resumo segundo os cinco critérios;
5. atribuir notas de 0,0 a 10,0, em passos de 0,1;
6. registrar observações, quando necessário;
7. revisar os valores preenchidos;
8. enviar a avaliação.

## Regras

- O avaliador deve analisar apenas os trabalhos atribuídos;
- as avaliações devem ser independentes;
- as notas devem refletir os critérios apresentados;
- após o envio, alterações dependerão das permissões definidas pela coordenação.
